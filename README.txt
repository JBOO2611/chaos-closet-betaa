CHAOS CLOSET CROSSLISTER v8 PRIVATE BETA

This version can run locally or be deployed as an invite-only private beta.

LOCAL
- Double-click RUN_CHAOS_CLOSET.bat
- Create your account first
- Use the app normally

CLOUD
- See DEPLOY_PRIVATE_BETA.txt
- Requires persistent storage for DATA_DIR
- Registration is protected by BETA_INVITE_CODE

UPGRADING FROM v7
v8 now stores runtime data under a data directory.
For local migration:
1. Extract v8.
2. Create a folder named data inside v8.
3. Copy your old chaos_closet.db into data.
4. Copy your old uploads folder into data/uploads.
5. Run the app.

The first account remains the owner/admin.
